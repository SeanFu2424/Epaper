## 当前进度：已完成 vs 待办

**已完成（讨论层面）**

- [x] 产品定义：**电子版 Pro Rider Stem Notes**，核心是 Course Awareness（不是缩小版 Garmin）
- [x] 架构分层：V0 硬件验证 → V1 PC 渲染位图 + 翻页 → V2 设备端渲染 → V3 GPX 自动生成
- [x] 三层显示结构：L1 下一个事件 / L2 未来列表 / L3 事件详情
- [x] 刷新策略：**1/3 误差预算规则**（t = 剩余距离 ÷ (3×均速)，下限 1 分钟、上限 30 分钟）
- [x] 硬件确认：ESP32-S3，非 C6；无经典蓝牙（只有 BLE）；deep sleep 唤醒脚 GPIO0–21

**待办（等板子/等资料）**

- [ ] 向店家要**资料包**（原理图 + 点屏 Demo）—— 没有它第 1 课无法完成
- [ ] 确认**屏幕驱动 IC**（SSD1680 / JD79653 / SSD1608？）
- [ ] 确认**触控版还是非触控版**
- [ ] 确认 **PWR 键是 GPIO 还是硬电源开关**（决定能否当"上一页"）
- [ ] 填完硬件资源表（GPIO / SPI 六线 / 实测刷新耗时与电流）

**已确定的关键决策**

1. **V1 走 SD 卡**：电脑渲染 BMP → 拷 SD 卡 → 设备读取翻页，跳过 USB/BLE/小程序开发
2. **中文用 PC 端渲染**：设备端不放字库，避免卡在字体和排版上（V2 再考虑子集化字库）
3. **图标必须单色自绘**：emoji 在 1-bit 屏上会糊成黑点
4. **单页 5000 字节**（200×200÷8），8MB Flash 可存上千页，存储无压力

## 关键数字备忘

| 项目 | 值 |
|---|---|
| 屏幕 | 1.54" 200×200 黑白，SPI |
| 全局刷新 / 局部刷新 | 2s / 0.3s |
| 单页位图大小 | 5000 字节 |
| MCU | ESP32-S3，双核 240MHz，512KB SRAM |
| Flash / PSRAM | 8MB / 8MB（Arduino 里 PSRAM 选 **OPI PSRAM**） |
| 无线 | Wi-Fi + BLE 5（**无经典蓝牙/SPP**） |
| deep sleep 唤醒脚 | GPIO0–21 |
| 板载 | RTC(PCF85063) / SHTC3 温湿度 / Micro SD / 音频 / 锂电管理 / PWR+BOOT 键 |

## 一条最重要的提醒

**BOOT 键 = GPIO0**，正常运行时可当按键，但**上电瞬间不能按住**（会进下载模式）。
