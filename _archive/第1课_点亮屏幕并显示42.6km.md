# 第 1 课：点亮屏幕，显示 "42.6 km"

> 适用硬件：ESP32-S3 + 1.54" 200×200 黑白墨水屏（SPI）+ 8MB Flash / 8MB PSRAM
> 本课目标：从拆快递到屏幕上出现 `42.6 km`。**不碰中文、不碰 Wi-Fi、不碰 BLE、不碰 GPX。**
> 预计时间：一个晚上（若环境顺利）

---

## 课前：先确认 4 件事（10 分钟，别跳过）

| 要确认的 | 为什么 | 怎么确认 |
|---|---|---|
| ① 是**触控版**还是**非触控版** | 触控版带 FT6336，I2C 占用不同引脚 | 商品订单详情 / 板子上有没有排线连到屏 |
| ② 厂商**资料包**在哪 | **这是本课能不能顺利的关键**：里面有引脚定义和点屏 Demo | 问客服要 / 商品页底部 / 包装上的二维码 |
| ③ 屏幕驱动 IC 型号 | 决定用哪个 GxEPD2 驱动类 | 资料包里找；或看厂商 Demo 的 `#include` |
| ④ USB 线**带数据** | 充电线会导致电脑认不到串口 | 换一根手机能传文件的线 |

> 200×200 的 1.54" 屏，常见驱动 IC 是 **SSD1680**、**JD79653** 或 **SSD1608**。GxEPD2 里对应的驱动类大致是 `GxEPD2_154_D67` / `GxEPD2_154_GDEY0154D67` 等——**必须以厂商 Demo 为准，不要猜**。

## 步骤 1：装 Arduino IDE

1. 下载 [Arduino IDE 2.x](https://www.arduino.cc/en/software)（选 2.3.x）
2. 打开 → **文件 → 首选项 → 附加开发板管理器网址**，填：

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

3. **工具 → 开发板 → 开发板管理器** → 搜 `esp32` → 安装 **esp32 by Espressif Systems**（选 3.x）

> **国内装不上是常态**（下载会卡住/超时）。三个办法按序尝试：
> ① 挂代理重试；② 搜"arduino-esp32 3.x 离线安装包"直接装 exe；③ 改用 **VS Code + PlatformIO**（走国内镜像，新建项目选 `Espressif ESP32-S3-DevKitC-1`）。
> 别跟 Board Manager 的进度条死磕超过 20 分钟。

---

## 步骤 2：板卡参数设置（S3 关键，照抄）

插上 USB，然后：

| 设置项 | 选什么 |
|---|---|
| Board | **ESP32S3 Dev Module** |
| Port | 出现的 COM / ttyUSB（mac 是 `/dev/cu.usbmodem...`） |
| **USB CDC On Boot** | **Enabled**（否则串口一个字都看不到） |
| USB Firmware MSC On Boot | Disabled |
| USB DFU On Boot | Disabled |
| CPU Frequency | 240MHz (WiFi) |
| Flash Mode | QIO 80MHz |
| Flash Size | 8MB (64Mb) |
| Partition Scheme | 8M with spiffs（约 3MB APP） |
| **PSRAM** | **OPI PSRAM** ← 选错就用不了那 8MB |
| Upload Mode | UART0 / Hardware CDC（默认） |

> S3 走原生 USB，一般**不用装 CH340/CP210x 驱动**。

## 步骤 3：第一个程序（先不碰屏幕）

```cpp
void setup() {
  Serial.begin(115200);
  delay(500);                 // 等 USB 枚举
  Serial.println("Hello ESP32-S3");
}

void loop() {
  Serial.println(millis());
  delay(1000);
}
```

上传 → **工具 → 串口监视器**，波特率设 **115200**。

**没有输出？** 按这个顺序排查：

1. 按一下板子上的 **RESET**（S3 上传后常常要手动复位）
2. 确认 `USB CDC On Boot = Enabled`
3. 换 USB 口 / 换线
4. 上传时若提示 `Connecting...` 卡住：**按住 BOOT → 点上传 → 出现进度后松开 BOOT**

看到 `Hello ESP32-S3` 就算过了第一关。

## 步骤 4：点亮屏幕

### 4.1 装库

**库管理器**（左侧书本图标）装两个：

- `GxEPD2`
- `Adafruit GFX Library`

### 4.2 先跑厂商 Demo（强烈建议）

如果资料包里有 `.ino` 示例，**先跑它**。因为引脚已经配好，成功率最高，而且能立刻确认：

- 屏幕型号与驱动类（看代码里的 `GxEPD2_xxx`）
- 六个引脚：CS / DC / RST / BUSY / SCK / MOSI

> **把这六个引脚抄下来**，填进 `硬件资源表`。这是你后面所有代码的基础。

### 4.3 没有厂商 Demo 时

用 GxEPD2 自带的示例：`文件 → 示例 → GxEPD2 → GxEPD2_Example`。
需要在文件顶部取消注释对应你屏幕的那一行驱动定义，并填对引脚。

## 步骤 5：显示 "42.6 km"

把厂商 Demo 里的引脚替换进下面这份代码：

```cpp
#include <GxEPD2_BW.h>
#include <Adafruit_GFX.h>
#include <Fonts/FreeMonoBold18pt7b.h>   // 够大又放得下

// ↓↓↓ 这几个数字必须换成你板子的真实引脚（从厂商 Demo 抄）
#define EPD_CS    10
#define EPD_DC     8
#define EPD_RST    9
#define EPD_BUSY   7
// SCK / MOSI 通常走默认 SPI，不用填

// ↓↓↓ 驱动类也要按你的驱动 IC 改（例：GxEPD2_154_D67）
GxEPD2_BW<GxEPD2_154_D67, GxEPD2_154_D67::HEIGHT>
  display(GxEPD2_154_D67(EPD_CS, EPD_DC, EPD_RST, EPD_BUSY));

void setup() {
  Serial.begin(115200);
  display.init(115200);          // 初始化，会打印诊断信息
  display.setRotation(0);        // 0/1/2/3 试出你想要的方向
  display.setTextColor(GxEPD_BLACK);

  display.setFullWindow();       // 全屏刷新
  display.firstPage();
  do {
    display.fillScreen(GxEPD_WHITE);
    display.setFont(&FreeMonoBold18pt7b);
    display.setCursor(24, 100);
    display.print("42.6 km");
  } while (display.nextPage());

  display.hibernate();           // 进低功耗，画面保持
  Serial.println("done");
}

void loop() {}
```

要点：

- `setFullWindow()` + `firstPage()/nextPage()` 是 GxEPD2 的**分页绘图**写法，必须这样写
- `hibernate()` 之后画面会**一直保持**，断电也不丢——这就是墨水屏的意义
- 第一次刷新会比较慢（全局刷新 2s），正常

## 步骤 6：加上大箭头（第二课预告）

`→` `↑` 这类符号，**不要**用 Unicode 字符（自带字体里没有）。用画图函数：

```cpp
// 右转箭头
display.fillTriangle(80, 70, 80, 110, 120, 90, GxEPD_BLACK);
display.fillRect(50, 85, 32, 10, GxEPD_BLACK);
```

等中文方案确定后，整页会改成 PC 渲染位图，这些手绘代码就不需要了。

## 故障排查表

| 现象 | 原因 | 处理 |
|---|---|---|
| 串口完全没反应 | USB CDC 没开 / 线不带数据 | 见步骤 2、步骤 3 |
| 上传失败 `Failed to connect` | S3 没进下载模式 | 按住 BOOT 再点上传 |
| 编译报 `GxEPD2_154_D67` 未定义 | 驱动类选错 | 换资料包里 Demo 用的那个类 |
| 屏幕全白无内容 | 引脚错 / 驱动类错 | 回头跑厂商 Demo 对照 |
| 屏幕花屏 | 供电不足或 SPI 速率过高 | 换 USB 口；`display.init(115200, true, 10, false)` 降速 |
| 有淡淡残影 | 正常，局部刷积累 | 做几次全刷；长期不用前清屏 |

## 顺带说：这块板子给了一个 V1 捷径

它**有 Micro SD 卡槽**——意味着你的 V1 可以完全跳过"数据传输"这一步：

```
电脑 Python 渲染页面 → 存成 .bmp → 拷贝到 SD 卡 → 插回板子 → 设备读取并翻页
```

不用写 USB 协议，不用写 BLE，不用做小程序。**V1 从"显示 + 翻页"直接可用**，工作量从几周压到几天。

所以不要把 V1 定义成"电脑 USB 传图"，改成 **"SD 卡装图"**。等 V2 做小程序时再解决无线传输。

另外两个暂时用不上但值得记住的：

- **SHTC3 温湿度**：墨水屏在低温下刷新变慢、对比度下降。有了温度传感器，以后可以做**温度补偿**（按温度调整刷新参数）——冬天骑车很有用
- **PCF85063 RTC**：比 S3 内部 RTC 计时器更准，且跨断电保持时间，将来做"出发后已用时"很方便
